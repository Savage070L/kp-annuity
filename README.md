# Генератор КП — пенсионный аннуитет

Страница, где агент вводит данные клиента и получает готовое коммерческое
предложение — HTML-файл в фирменном стиле Standard Life.

## Как пользоваться

1. Откройте `index.html` — двойным кликом или по ссылке GitHub Pages.
2. Один раз заполните блок «Агент» — он запоминается в этом браузере.
3. Введите клиента: имя, пол, дату рождения, накопления в ЕНПФ, гарантированный период.
4. Справа сразу видно готовое КП, слева — сводка расчёта.
5. «Скачать КП» — файл для отправки клиенту (WhatsApp, Telegram, почта).
   «Печать / PDF» — открывает КП и диалог печати, там же «Сохранить как PDF».

Всё считается в браузере — данные клиентов никуда не отправляются.

## Откуда цифры

Расчёт перенесён из калькулятора компании «ПА калькулятор 21.09.2026.xlsx»
(`src/engine.js`) и сверен с ним через LibreOffice на 7 профилях — расхождений нет.

| параметр | значение | ячейка Excel |
|---|---|---|
| ставка доходности | 9% | calc!B1 |
| индексация | 8% | calc!B2 |
| расходы от премии / от выплаты | 1,5% / 3% | calc!B3, B4 |
| прожиточный минимум | 50 851 ₸ | calc!H1 |
| минимальная выплата | 70% ПМ | calc!H2 |
| гарантированный период | не больше 10 лет | ввод!G14 |
| таблицы смертности | по полу и категории | calc!J:U |

Таблица выплат по годам: выплата растёт на 8% каждый год от первой выплаты
в момент выхода на пенсию.

## Если компания обновит калькулятор

- Изменились ставки или ПМ — поправьте `TARIFF` в `src/engine.js`.
- Изменились таблицы смертности — пересоберите `src/mort-compact.json`
  из листа `calc` нового файла.
- После правок: `node tools/build.js` — пересоберёт `index.html`.
- Проверка: `node test/smoke.js` — прогон тестовых клиентов.

## Структура

```
index.html              готовая страница генератора (собирается)
src/engine.js           расчёт по калькулятору компании
src/report-model.js     цифры и тексты КП из результата расчёта
src/report/sections/    разделы КП — шаблоны
src/report/blocks.js    таблицы, диаграммы, сетки
src/report/*.css, *.js  стили и скрипт самого КП
src/generator.html      страница генератора (форма и предпросмотр)
tools/build.js          сборка
test/                   проверки
```
