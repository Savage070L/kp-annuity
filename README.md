# Генератор КП — пенсионный аннуитет

Страница, где агент вводит данные клиента и получает готовое коммерческое
предложение — HTML-файл в фирменном стиле Standard Life.

## Как пользоваться

1. Откройте `index.html` — двойным кликом или по ссылке GitHub Pages.
2. Один раз заполните блок «Агент» — он запоминается в этом браузере.
3. Введите клиента: имя, пол, дату рождения, накопления в ЕНПФ, гарантированный период.
   Дату можно набрать одними цифрами: `050482` или `05041982` → 05.04.1982.
4. Справа сразу видно готовое КП, слева — сводка расчёта.
5. «Скачать КП» — файл для отправки клиенту (WhatsApp, Telegram, почта).
   «Печать / PDF» — открывает КП и диалог печати, там же «Сохранить как PDF».

Всё считается в браузере — данные клиентов никуда не отправляются.

## Новый калькулятор компании

Код менять не нужно. В карточке «Калькулятор» нажмите «Загрузить .xlsx»
или перетащите файл на страницу — генератор подставит клиента во входные ячейки
файла и возьмёт порог, возраст начала выплат, аннуитетный фактор и выплаты
из формул самого файла. Файл запоминается в этом браузере;
«Вернуть встроенный калькулятор» — обратно к встроенному.

После загрузки карточка показывает:

- параметры из файла: ставку, индексацию, ПМ, минимальную выплату, предел гарантии;
- что изменилось по сравнению со встроенным калькулятором: ставки, ПМ,
  возраст начала выплат, таблицы смертности, категории;
- проверку: формулы, от которых зависит расчёт, пересчитываются
  и сверяются с результатами, которые сохранил сам Excel.

Как генератор находит ячейки: по именам книги (`DofB`, `дата_расч`, `sex`, `OPPV`, `gp`,
`BP`, `x`, `x0`, `x_0`, `d`, `nax`, `i`, `ind`, `alfa`, `gamma`), а где имён нет — по подписям
рядом: «Категория», «Накопления с ЕНПФ», «Выкупная сумма», «Взнос клиента»,
«Минимальная премия», «Прожиточный минимум», «выплата на дату заключения»,
«выплата в момент выхода на пенс». Категории берутся из выпадающего списка файла.
Если в новом файле переименуют эти ячейки или появится функция Excel,
которую генератор не знает, карточка скажет, чего не хватает.

## Встроенный калькулятор

Перенос «ПА калькулятор 21.09.2026.xlsx» в код (`src/engine.js`) — работает, пока файл
не загружен. Совпадает с расчётом по самому файлу до тенге на 1 500 случайных клиентах.

| параметр | значение | ячейка Excel |
|---|---|---|
| ставка доходности | 9% | calc!B1 |
| индексация | 8% | calc!B2 |
| расходы от премии / от выплаты | 1,5% / 3% | calc!B3, B4 |
| прожиточный минимум | 50 851 ₸ | calc!H1 |
| минимальная выплата | 70% ПМ | calc!H2 |
| гарантированный период | не больше 10 лет | ввод!G14 |
| таблицы смертности | по полу и категории | calc!J:U |

Таблица выплат по годам — как лист «График» калькулятора: раз в год
выплата = ROUND(прошлая выплата · (1 + индексация)), за год — 12 одинаковых выплат.

## Проверки

- `node test/compare-excel.js` — встроенный расчёт против ответов Excel (пересчитан в LibreOffice), 7 профилей;
- `node test/xlsx-engine.js` — расчёт по файлу: сверка формул с сохранёнными значениями Excel,
  7 профилей и 1 500 случайных клиентов против встроенного. Нужен сам файл калькулятора:
  `KP_XLSX=путь/к/файлу.xlsx node test/xlsx-engine.js`;
- `node test/smoke.js` — все тестовые КП собираются без пустых мест.

После правок в `src/` — `node tools/build.js`, он пересоберёт `index.html`.

## Структура

```
index.html              готовая страница генератора (собирается)
src/engine.js           встроенный расчёт по калькулятору 21.09.2026
src/xlsx.js             чтение .xlsx: листы, формулы, имена, списки
src/formula.js          формулы Excel: разбор и вычисление
src/calc-xlsx.js        калькулятор из файла: входные и выходные ячейки, проверка
src/report-model.js     цифры и тексты КП из результата расчёта
src/report/sections/    разделы КП — шаблоны
src/report/blocks.js    таблицы, диаграммы, сетки
src/report/*.css, *.js  стили и скрипт самого КП
src/generator.html      страница генератора (форма и предпросмотр)
tools/build.js          сборка
test/                   проверки
```
